## B. Language & culture

| ID | Decision |
|---|---|
| B1 | **Hebrew-first.** Entire UI, narration, characters, parent area in Hebrew, RTL. English is taught as a subject inside the Hebrew app. |
| B2 | English content lives in **LTR "English islands"** (separate pages/cards), voiced by a dedicated English-only character ("one person, one language"), with a distinct visual + audio cue (jingle, color accent) when entering English. Hebrew gloss via "sandwich" (EN → HE → EN) for K2; English-only islands grow over time for K1. |
| B3 | **Grammatical gender:** every child-directed string has variants `m`/`f`/`pl` (and `n` neutral where possible). Prefer neutral constructions (infinitive, "בואו נ…", child's name). Gender is a profile field; LLM/TTS never choose gender. Snapshot tests render every screen per profile. |
| B4 | **Numbers spoken aloud** come from a hand-checked lookup table (gendered numerals, construct forms), never from free TTS/LLM. Rote counting uses feminine forms (as in Israeli gan). |
| B5 | **Nikud:** full nikud for all K2 text and K1 by default; K1 follows a nikud-fade track (pointed → partial → unpointed) aligned with mid-grade-3 unpointed reading (~Feb 2027). Nikud generated by Dicta Nakdan (or Phonikud), validated, human-spot-checked. Font must render nikud correctly on iOS (test early on device). |
| B6 | **Best practice beats local convention.** Align topics/timing with the Israeli curriculum and school calendar, but when evidence-based global practice conflicts with common Israeli methods, follow the evidence (e.g., letter sounds before names, systematic phonics, CPA math, number-line games, spaced retrieval). |
| B7 | Israeli/Jewish calendar: week starts Sunday; Shabbat & holidays auto-pause streak/goal counters and notifications (opt-out per family); holiday seasonal events (Rosh Hashana, Sukkot, Hanukkah, Tu BiShvat, Purim, Pesach, Yom HaAtzmaut, Shavuot). Memorial days: no celebratory events. |
| B8 | Security-situation sensitivity: no siren-like sounds, explosions, alarms, or war/current-events content. Optional offline calm "safe room" mode. |

## C. Pedagogy & ethics guardrails

| ID | Decision |
|---|---|
| C1 | **Intrinsic integration:** the learning action IS the game action (e.g., attack = solve; build = measure/multiply). Avoid quiz-between-levels. |
| C2 | **Target success bands:** K3 ≈ 90–95% (no fail states), K2 ≈ 85%, K1 75–85% with opt-in Stretch Zone. |
| C3 | **Episode lengths:** K3 3–5 min (co-play only, "lap mode"), K2 8–12 min, K1 15–20 min. Parent-set daily caps. Sessions are finite episodes with a wind-down; no autoplay. |
| C4 | **Praise:** process/strategy praise only. No trait praise ("גאון", "אלוף", "חכם"), no inflated superlatives. Approved/banned phrase lists live in the UX spec. |
| C5 | **No loss mechanics:** no hearts/energy, no streak loss, nothing wilts or dies, no fake timers, no nagging, no FOMO. Weekly **family goal** instead of daily streaks; auto rest days on Shabbat/holidays. |
| C6 | **No sibling comparison:** no leaderboards/side-by-side scores. Co-op with different roles per child. K1 "guide/teacher" mode is opt-in, capped, and rewards her own progress. |
| C7 | **AI for kids:** no open-ended chat for any child. Structured, scripted, sandboxed AI interactions only; "try first, then AI"; hints not answers; AI clearly labeled as a machine (separate from the scripted mascot). Content kids see is pre-generated and validated (and parent-approvable). |
| C8 | **Not therapy:** SEL/CBT-informed activities only; emotional check-ins stored on device or not at all; red flags surface to parents only, non-diagnostic, with referral paths (יועצת, אבחון דידקטי, קלינאית תקשורת, ריפוי בעיסוק, רופא/ת ילדים). |
| C9 | **Profiling:** strengths-based, dynamic, context-tagged (not trait labels), parent-visible and correctable; kids see only a "my strengths" view; recommendations never by gender; 20–30% exploration share. |
| C10 | Phygital bridge: printable missions/worksheets (free handwriting for K2 letters), offline missions, family rituals. In-app accuracy is not the success metric; periodic paper probes + teacher feedback are. |

## D. Gamification & economy (parent's explicit request — keep, design ethically)

| ID | Decision |
|---|---|
| D1 | Currencies: **מטבעות (coins)** = soft currency earned from mastery events & effort (not raw time); **יהלומים (gems)** = rare, earned only at milestones (skill mastered, boss beaten, weekly family goal, holiday event). **No real money, ever.** No purchases of currency. |
| D2 | **Chests/treasures (תיבות/אוצרות):** contents are fixed at earn time and shown (or guaranteed) before opening; "rarity" reflects what earned it, never chance. Big juicy reveal animation is allowed and encouraged. |
| D3 | **Cosmetic-only shop** (avatar outfits, emotes, base decorations, pet accessories, trails). Items rotate but always return; wishlist + save-up goals; no countdowns. |
| D4 | Levels/XP per child, skill badges named after the skill learned, collectible pets that evolve with mastery (never die), season album that never expires, home base building as reward sink, family campfire upgrades as shared sink. |
| D5 | K3: stickers only (no currencies). K2: coins + simple chests + pet. K1: full economy (coins, gems, chests, shop, pass-like season track without paywall). |
| D6 | Real-world rewards set by parent, behind parent gate, framed as family activities tied to effort goals; never announced in advance as contingent prizes for specific tasks. |
